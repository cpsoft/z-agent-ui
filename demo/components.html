L1 控件

数据录入、展示与操作的基础件：不带业务逻辑，不取数、不管路由。 按「你想干什么」分成 8 个家族 —— 录入表单、按钮命令、排版、展示、数据、导航、反馈、移动端。

先按场景找，再进详情页看参数

每个家族下面都有可直接操作的示例；点组件名进详情页，那里有完整的属性 / 事件 / 插槽表。 组合件（属性面板 / 详情表单 / 代码编辑器）在 L3 编辑器页， 报表表格 / 甘特 / 图表在 L2 报表页。

Embed

把一份完整的 HTML 文档嵌进页面。用 iframe 而不是 innerHTML：报告自带的 <style> 会改掉整页排版，一段脚本能直接读宿主的存储与 DOM。两种来源二选一：src（外部地址或站内相对路径）与 html（已生成的 HTML 字符串，走 srcdoc）。默认不给脚本（sandbox="allow-same-origin"），需要图表脚本时显式写 sandbox="allow-scripts allow-same-origin"。
