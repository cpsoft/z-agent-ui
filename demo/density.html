密度与尺寸

两个旋钮，名字容易被混成一件事：密度改令牌，size 改对令牌的引用。 所以局部永远赢，而密度仍是那一档的基线 —— compact 下放一个 size="lg" 的输入框， 它会是 32px 而不是 36px。

谁改什么

两个旋钮管的事不一样：密度是全局的，size 是单组件的。两者同时生效时，size 决定这一个控件的高度。

旋钮作用域做法
密度全局（<html data-density>）覆盖 --z-control-h-* 一整组令牌，页面上所有控件一起变紧或变松
size单组件（size="xs|sm|md|lg"）只改控件外壳高度，映射到上面那组令牌里的某一个 —— 不写死像素

哪些控件有 size

自己有外壳的控件（画边框 / 背景 / 内边距）才有四档高度；其余控件的尺寸由内容或使用场景决定。

类别组件说明
有外壳 → 四档高度z-input z-select z-number-input z-pagination控件盒高由自己决定，size 就是盒高
无外壳 → size 指图形z-checkbox z-radio z-slider z-rate它们改的是方框/轨道/星标尺寸，与「盒子 32px」不是一回事
高度由内容决定z-textarea高度是 rows / autosize 的事
外壳来自内在控件z-datepicker z-time-picker z-date-range触发框由消费方塞进去的 z-input 决定
