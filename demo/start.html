安装与入口

零运行时依赖的 Web Components 库。装一次，按需引入口 —— 入口分两层： 根入口 @cpsoft13/z-agent-ui 只给 L0 工具（基类、模板、词汇表），一个组件都不注册； 组件由域入口或单个组件入口注册，引哪个就注册哪些元素。 入口清单在下面，从 package.json 的 exports 现算，不是手写的表格：手写一定会过时。

只引根入口会看到「标签不渲染」：未注册的自定义元素被当作行内元素处理 —— 不报错、样式不生效、内容直接消失。遇到这种情况，先查入口有没有引到，再查标签名有没有拼错。

三行装好

没有构建插件、没有 CSS-in-JS、没有 provider；自定义元素注册与样式表都由入口自己完成， 所以「引哪一行」决定了「哪些标签能用」。

# 1. 装
npm i @cpsoft13/z-agent-ui

# 2. 引样式 + 组件入口（根入口 @cpsoft13/z-agent-ui 只有 L0 工具，引它不会注册任何组件）
import "@cpsoft13/z-agent-ui/z-agent-ui.css";
import "@cpsoft13/z-agent-ui/components/button";

# 3. 直接用，标签即组件
<z-button variant="primary">保存</z-button>
