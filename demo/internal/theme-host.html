怎么判「零侵入成立」
  1. 勾上「注入宿主主题」后，页面底与卡片面必须不同（#f8fafc vs #ffffff）。只换主色不换层次 = 失败。
  2. 主色、圆角、边框、字体同时跟随；任一没跟，说明那条 token 还没桥接。
  3. 切「暗色」时两条通道（data-theme / .dark class）结果必须一致。
  4. 切密度后，表格行高、按钮、输入框、分页按钮同时变紧或变松。
  5. 无论怎么切，文字都清晰可读（WCAG AA 4.5:1）。
