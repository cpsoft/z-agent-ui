L0 地基

模板、转义、令牌桥、浮层定位、焦点陷阱。这一层不含任何控件外观 —— 它存在的理由是让上面三层说同一种语言：一套属性声明、一套 HTML 构造、一套浮层与焦点管理、一套色值。

三个目录

层与 src 一级目录 1:1。看到目录名就知道它属于哪一层，不用查表。

目录管什么边界
core模板 / 转义 / 令牌桥 / 日期算术 / 尺寸语义零 import —— 不引组件、不引 theme。纯函数与常量，谁都能用
primitives浮层定位、焦点陷阱、元素引用碰 DOM，但不知道「弹窗」是什么；只管「贴哪、谁能按 Tab」
theme令牌、明暗、密度只产出 CSS 变量，不含任何选择器知识

机制件

这些组件不直接出现在页面上，而是被每个浮层用到： focus-trap / click-outside 管「按 Tab 怎么走、点到外面关不关」； z-portal 与 z-position 的输出看得见（节点搬出去、浮层贴上锚点），下面直接跑给你看。
