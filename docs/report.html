L2 报表

表格内核、图表、甘特、选列、数据列表。这一域是自带数据契约的复合件：有自己的行模型、排序与聚合口径，但仍然不取数、不管路由。

表格 / 甘特 / 图表都在本页，可直接操作

三段示例彼此独立：表格管行模型与聚合，甘特管时间轴，图表管趋势，要哪个抄哪个。 需要「筛选 + 报表 + 导出」的整页拼装，去 L3 页面引擎。

这一域有哪些件

这一域的组件都在 src/report/ 下；列表与计数是自动生成的，新加组件会自己出现。

Radar

        
Multi-axis profile. Each axis is normalized by the largest value across series, so axes can carry different units (¥, cups, %). Series sharing an axis must be the same metric (store vs region average, this year vs last) — two different metrics in one radar squash the smaller one. Fewer than 3 axes is treated as no data.

      


      

        

          
            
            
          
        

        

          Show Code
        

        


<z-chart type="radar" title="Store Profile: Binjiang vs Region Average" width="440" height="360">
  <z-chart-series name="滨江店"></z-chart-series>
  <z-chart-series name="区域均值"></z-chart-series>
</z-chart>
// 每个系列一组 {label, value}；label 即轴名，各系列顺序必须一致
shop.data = [{ label: "营业额", value: 128000 }, { label: "出杯量", value: 820 }, { label: "客单价", value: 32.5 }, { label: "实收率", value: 0.86 }, { label: "复购率", value: 0.42 }, { label: "达成率", value: 1.08 }];
// 逐轴归一：每根轴的分母是「所有系列在该轴上的最大值」→ 顶点越靠外 = 该轴越强
// 系列必须是同一指标的不同主体（本店 vs 区域均值）；销售额与订单数混在一张雷达里，小的会被压到圆心

Report card

        
看板上的一张卡。给一份 dataSource 与一个 chart 配置，
        卡自己负责查询、竞态、骨架屏、错误态、导出。

      


      

        

          

          
三张卡共用同一份 mock 数据源：指标卡 / 表格卡 / 明细卡。数字是真算出来的，不是写死的。

        

        

          Show Code
        

        


/* chart 是 **Object 属性**（attribute: false），用 property 赋值 */
const el = document.createElement("z-report-card");
el.chart = {
  id: "c-kpi", chartType: "kpi", title: "销售额（今日）",
  datasetId: 1, rows: [], filters: [], limit: 1000,
  measures: [{ field: "sales", agg: "sum", alias: "销售额" }],
};
el.dataSource = myDataSource;   // 四个必填方法：元数据 / 聚合 / 明细 / 值搜索
host.appendChild(el);

/* 旧写法（仍可用，但不要在新代码里写） */
