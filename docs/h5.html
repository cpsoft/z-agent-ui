移动端 H5

为触屏重做的一套控件与版面：44px 命中区、安全区、常驻底栏。 右边是一部常驻的手机 —— 往下滚，它就演当前这一段；手机里的控件能真的滑动、下拉、弹层。

快速开始

一个 H5 页面就是「顶栏 + 一个滚动区 + 固定在壳底的几层」。抄这段骨架，三处细节见下。

import "z-agent-ui/components/button";
import "z-agent-ui/components/m-navbar";
import "z-agent-ui/components/m-cell";
import "z-agent-ui/components/m-tabbar";

<div class="h5-page">                       <!-- 壳：有边界、overflow:hidden、transform:translateZ(0) -->
  <m-navbar title="门店" showback></m-navbar>
  <div class="h5-page__scroll">              <!-- flex:1; min-height:0; overflow-y:auto -->
    <m-cell label="望江店" value="营业中"></m-cell>
  </div>
  <m-tabbar items="[…]" active="home"></m-tabbar>   <!-- fixed：钉在壳底 -->
</div>
  1. 壳要有 transform。tabbar / 操作条 / 数字键盘 / 悬浮按钮都是 position:fixed， 而 fixed 的参照是视口。壳上给一层 transform:translateZ(0)，它们才会钉在壳底。
  2. 滚动区要 min-height:0。flex 子项的最小高度默认是内容高度，不写这条就没有滚动条； 索引条、吸顶标题也会失去参照。
  3. 安全区已内置。tabbar / action-bar / action-sheet 自己垫 env(safe-area-inset-bottom)， 外层不要再加 padding，否则多一道空白。
